A post image can be a PNG, a JPEG, a WebP, a GIF, or an AVIF. This post has one of each, plus a JPEG that spells its extension the long way.

| Format | Extension | Image                         |
| ------ | --------- | ----------------------------- |
| PNG    | `.png`    | ![PNG](./images/format.png)   |
| JPEG   | `.jpg`    | ![JPEG](./images/format.jpg)  |
| JPEG   | `.jpeg`   | ![JPEG](./images/format.jpeg) |
| WebP   | `.webp`   | ![WebP](./images/format.webp) |
| GIF    | `.gif`    | ![GIF](./images/format.gif)   |
| AVIF   | `.avif`   | ![AVIF](./images/format.avif) |

The API keeps an image small enough to fit a thumbnail's size budget as it was uploaded, and makes a smaller WebP copy of a bigger one.
