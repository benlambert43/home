# home

Ben Lambert's personal website.
Uses npm workspace.

| Package       |                                  |
| ------------- | -------------------------------- |
| `home-web-ui` | Next.js site.                    |
| `home-server` | Express + mongoose API.          |
| `home-shared` | Shared frontend + backend types. |

## Commands

docker compose up -d

npm run dev

npm run dev:server

All timestamp strings should be in ISO 8601 format.
